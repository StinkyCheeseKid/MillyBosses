# MillyBosses

MillyBosses 1.1.19 with nine ModelEngine blueprints. Use Java 21 and Paper/Purpur 1.21.11. Install ModelEngine 4, Vault, and an economy provider separately. Copy plugins/ into your server plugins folder. Generate and distribute the ModelEngine resource pack to players. See LICENSE for the supplied license.

This repository contains the built plugin and its applicable model/resource assets.
Test servers, worlds, logs, player data, and development source are excluded.
